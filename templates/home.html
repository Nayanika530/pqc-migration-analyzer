Answers

Who is this platform for? +
Qryptis is engineered for security engineers, software architects, cryptographers, and DevSecOps teams responsible for discovering legacy cryptography and ensuring compliance with NIST post-quantum migration mandates.
What exactly is Qryptis? +
Qryptis is an automated static security scanner and migration platform that detects vulnerable classical algorithms (RSA, ECC, 3DES, MD5), calculates Cryptographic Agility Scores, models Harvest Now Decrypt Later (HNDL) exposure, and generates NIST PQC compliant CBOMs.
What can I save and scan here? +
You can scan full source code repositories, individual code files (.py, .js, .java, .c, etc.), manual algorithm and key size parameters, and live external HTTPS endpoints for TLS handshake validation.
What does "analyzing a codebase" mean? +
Our scanner parses your code to locate every cryptographic library initialization, evaluates whether the algorithm and key length will withstand Shor's and Grover's quantum algorithms, and attaches drop-in NIST PQC replacement code.
Wait, there's a built-in CLI and CBOM export? +
Yes! Real security engineers can run python qryptis.py scan ./src --export cbom.json directly in their terminal and enforce CI/CD build gates using --fail-on CRITICAL.
What are NIST FIPS 203 (ML-KEM) and FIPS 204 (ML-DSA)? +
In August 2024, NIST released finalized post-quantum standards: ML-KEM (FIPS 203) for key encapsulation and ML-DSA (FIPS 204) for digital signatures. Qryptis recommends these standardized lattice-based algorithms.
