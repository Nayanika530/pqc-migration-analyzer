🔬 Scientific Methodology: Why AST Trumps Regex

Traditional regex-based scanners match literal strings such as "RSA" or "AES" in variable names, comments, and dictionary keys, generating severe false positive rates. Qryptis constructs an Abstract Syntax Tree (AST) using Python's ast.NodeVisitor to parse call expressions structurally:

Assignment
 ├── variable: key
 └── CallExpression
     ├── func: RSA.generate
     └── arg: 2048 (Literal Integer)

This structural validation guarantees that only actual cryptographic API calls are flagged, completely suppressing false alarms in clean business logic.
